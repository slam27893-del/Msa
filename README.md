# المساعد الدراسي الذكي — Prototype v0.1

تطبيق **Android حقيقي** (Kotlin + Jetpack Compose) يساعد الطالب على معرفة مواده اليوم وغدًا،
وتسلسل دروس كل مادة (الدرس الحالي/القادم/المكتمل/الفائت)، ونسبة تقدمه في الفصل.

> **حالة المشروع:** Prototype أولي للتجربة والمراجعة — ليس النسخة النهائية.
> بيانات المنهج **تجريبية** لثلاث مواد فقط، ولا يوجد أي بيانات حقيقية لطلاب.

---

## ماذا يفعل الـ Prototype؟

| الميزة | الوصف |
|---|---|
| إعداد الطالب | ثانوي / أول ثانوي / الفصل الأول / مسار تجريبي |
| بيانات منهج تجريبية | 3 مواد × 3 وحدات × 3 دروس (27 درسًا) مع أهداف ومفاهيم وملخص لكل درس |
| الجدول الأسبوعي | تحديد مواد كل يوم (بدون أوقات حصص) |
| الصفحة الرئيسية | **«وش عندك غدًا؟»** مع الدرس القادم لكل مادة |
| تسجيل اليوم | زر **«حضرت اليوم»** + حالة لكل مادة: تم أخذ الدرس / لم نأخذ الدرس / غياب |
| الدروس الفائتة | دروس الغياب التي لم تُسجَّل أُخذت لاحقًا |
| اختيار يدوي | تعيين أي درس كدرس حالي (مع تأكيد إذا كان بعيدًا) |
| تعدد الدروس | تعليم أكثر من درس كمأخوذ دفعة واحدة |
| التقدم | عدد الدروس المكتملة/الإجمالي/النسبة لكل مادة + إجمالي الفصل |
| المظهر | وضع فاتح / داكن / تلقائي، وواجهة عربية RTL |

### قواعد منطق التقدم (الأساس الذي بُني عليه كل شيء)

- **تم أخذ الدرس** ← ينتقل الدرس الحالي إلى الدرس التالي.
- **لم نأخذ الدرس** ← لا يتغير الدرس الحالي.
- **غياب** ← لا يتغير الدرس الحالي + يُسجَّل الدرس في «الدروس الفائتة» بتاريخه.
  (**غياب الطالب لا يعني أن الدرس تم أخذه**)
- الدرس الفائت يبقى في القائمة حتى يتجاوزه الدرس الحالي (أي يُسجَّل أُخذ لاحقًا).
- «حضرت اليوم» بدون أي تعديل = «تم أخذ الدرس» لكل مواد اليوم المجدولة.

## بنية المشروع

```
Msa/
├── app/                  ← واجهة المستخدم (Compose) + التنقل + الثيم + التخزين على الجهاز
├── core/
│   ├── model/            ← نماذج البيانات (الطالب، المنهج، الجدول، الأحداث، الحالة)
│   ├── curriculum/       ← بيانات المنهج التجريبية (منفصلة تمامًا عن الواجهة)
│   ├── domain/           ← منطق تقدم الطالب (محرك الحساب من الأحداث)
│   └── storage/          ← التخزين المحلي (JSON في مخزن مفتاح/قيمة)
├── tools/
│   └── run-local-smoke.sh ← اختبار منطق سريع بدون Gradle (JDK + kotlinc فقط)
└── .github/workflows/    ← بناء تلقائي: اختبارات + APK
```

### فكرة التصميم: أحداث بدل تعديلات مباشرة (Event Sourcing مبسّط)

التطبيق لا يخزّن «التقدم» نفسه؛ بل يخزّن **سجل أحداث** (`StudentEvent`):
تسجيل يوم دراسي، تعليم دروس كمأخوذة، تعيين الدرس الحالي.
ثم يُشتق التقدم دائمًا بإعادة تشغيل الأحداث عبر `StudentProgressCalculator`.

الفائدة: تعديل تسجيل يوم سابق (تغيير «أُخذ» إلى «غياب» مثلًا) آمن ومتسق دائمًا،
والمنطق كله قابل للاختبار كدوال نقية بدون أي واجهة.

### فصل الطبقات (للتوسعة لاحقًا)

- **المنهج:** يأتي من واجهة `CurriculumDataSource` — استبدال `SampleCurriculum`
  بمصدر حقيقي (ملفات/قاعدة بيانات/سحابة) لا يلمس أي شيء آخر.
- **التخزين:** عبر واجهة `KeyValueStore` — الآن SharedPreferences، ولاحقًا DataStore/Room.
- **الحسابات/السحابة/AI/الإشعارات/OCR:** غير موجودة في هذه النسخة عمدًا؛ البنية جاهزة لإضافتها لاحقًا.

## التشغيل

### من Android Studio
افتح المجلد كمشروع Android (يتطلب JDK 17)، ثم Run على جهاز/محاكي (minSdk 26 = Android 8.0).

### من سطر الأوامر
```bash
./gradlew assembleDebug      # بناء الـ APK
./gradlew test               # اختبارات الوحدات (منطق التقدم + التخزين + بيانات المنهج)
```

### APK جاهز
حمّل آخر نسخة مباشرة من [Releases ← Prototype](https://github.com/slam27893-del/Msa/releases/tag/prototype)
(يُبنى تلقائيًا مع كل دفعة — `app-debug.apk` قابل للتثبيت مباشرة على أي جهاز Android 8.0+).

سير العمل الرسمي في `.github/workflows/build.yml` — نسخته المرجعية محفوظة في
`tools/ci-workflow.yml` (مطابقة تمامًا)، وكل منطق البناء داخل `tools/ci.sh`
حتى يمكن تعديل البنية دون لمس ملف سير العمل نفسه.
عند كل دفعة: تُشغَّل الاختبارات ويُبنى الـ APK ويُنشر في **Releases** بعنوان «Prototype».

### اختبار منطق سريع بدون أي أدوات أندرويد
```bash
tools/run-local-smoke.sh    # يحتاج JDK 17 و kotlinc فقط
```

## التخزين والخصوصية

- كل البيانات **محلية على الجهاز** (JSON في SharedPreferences) ولا تُرسل لأي مكان.
- البيانات تبقى بعد إغلاق التطبيق وإعادة فتحه (تُحفظ فورًا مع كل تعديل).
- لا يوجد تسجيل دخول ولا Backend في هذه المرحلة.

## خارج نطاق هذه النسخة (عمدًا)

لا يوجد: Streak أو Gamification أو AI أو إشعارات أو حسابات مستخدمين أو قاعدة بيانات سحابية أو OCR،
ولا المناهج السعودية الكاملة — كلها مرشحة للمراحل القادمة بعد مراجعة هذا الـ Prototype.
